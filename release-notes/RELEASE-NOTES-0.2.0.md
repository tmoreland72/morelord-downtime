# Morelord Downtime 0.2.0

Downtime opens from the Morelord Tools scene control.

## What Changed

### Improvements

- The Downtime timer control registers with Morelord Tools and remains available to GMs and players. It requires Morelord Core 0.6.0 or newer. When that tools registry is unavailable, the timer button stays on the Token controls.

## Verification

Automated module tests cover registry registration, the initializing warning, and the Token-controls fallback. Live Foundry verification of the Morelord Tools control is still outstanding.
